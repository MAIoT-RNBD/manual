리눅스 데스크탑 설치 매뉴얼

우분투 데스크탑을 새 PC에 설치하고, 정전에도 알아서 다시 켜지고 원격으로 관리되는 장비로 세팅하는 전 과정. 각 단계마다 GUI(화면 클릭)와 CLI(명령어) 두 방법을 같이 적었습니다. 담당자가 바뀌어도 이 문서만 보고 똑같이 따라 할 수 있도록.

1. 우분투 데스크탑 설치

USB로 부팅 미디어를 만들고, 그 USB로 PC를 켠 뒤 설치 마법사를 따라가면 끝납니다.

1) 설치 USB 만들기

  1. USB를 꽂고 Rufus(Windows) 또는 balenaEtcher(공용)를 실행
  2. 장치(Device)에서 꽂은 USB가 맞는지 두 번 확인 — 다른 디스크를 고르면 그 디스크가 지워집니다
  3. 부팅 선택(Boot selection)에서 다운로드한 우분투 ISO 지정
  4. Rufus는 파티션 방식 GPT / 대상 UEFI 기본값 그대로 → 시작(START)
  5. "ISO 모드로 쓰기" 물어보면 ISO Image mode 선택 → 완료까지 대기

디스크 식별자를 반드시 먼저 확인하세요. 틀리면 엉뚱한 디스크가 통째로 지워집니다.

# 리눅스: 꽂기 전후로 비교해 USB 장치명 확인 (예: /dev/sdb)
lsblk

# 굽기 (sdX 를 실제 USB 장치명으로 — 숫자 파티션 말고 디스크 전체)
sudo dd if=~/Downloads/ubuntu-24.04-desktop-amd64.iso of=/dev/sdX bs=4M status=progress oflag=sync

# macOS: diskutil 로 식별 후 rdiskN 사용
diskutil list
diskutil unmountDisk /dev/diskN
sudo dd if=ubuntu.iso of=/dev/rdiskN bs=4m
🚨
dd는 확인 질문 없이 바로 덮어씁니다. of= 뒤 장치명이 USB가 맞는지 세 번 확인하세요. 내장 디스크를 지정하면 OS가 통째로 날아갑니다.

2) USB로 부팅

  1. 설치할 PC에 USB를 꽂고 전원을 켜자마자 부팅 메뉴 키를 연타: 보통 F12 F10 F2 Esc Del 중 하나 (제조사별로 다름 — 화면 하단 안내 확인)
  2. 부팅 장치 목록에서 USB(UEFI: ...) 항목 선택
  3. 검은 화면 메뉴에서 Try or Install Ubuntu 선택
⚠️
USB로 안 넘어가고 기존 OS로 부팅되면, BIOS의 Boot Order(부팅 순서)에서 USB를 1순위로 올리거나, Secure Boot를 잠시 끄면 됩니다. (BIOS 진입은 2번 섹션 참고)

3) 설치 마법사

  1. 언어 한국어 → 키보드 Korean
  2. 업데이트와 기타 소프트웨어: "일반 설치", "설치 중 업데이트 다운로드"·"서드파티 드라이버 설치" 체크 권장
  3. 설치 형식: 이 디스크를 통째로 쓸 거면 디스크를 지우고 Ubuntu 설치 (기존 데이터 삭제됨 — 주의)
  4. 지역/시간대: Seoul
  5. 계정 만들기 — 아래 표대로. 자동 로그인은 4번 섹션에서 따로 켭니다(설치 화면에서 켜도 됨)
  6. 설치 완료 → USB 뽑고 재부팅
이름 / 컴퓨터 이름호스트명은 알아보기 쉽게 (예: line1-pc, kiosk-01)
사용자 이름소문자 영문 (예: maiot). 이게 곧 로그인 계정·홈 폴더명
비밀번호적당히 정하되 기록해 두기. sudo·복구에 계속 쓰입니다

4) 첫 부팅 후 — 시스템 업데이트

# 패키지 목록 갱신 + 전체 업그레이드 (이후 모든 설치의 기본)
sudo apt update
sudo apt upgrade -y
✅
여기까지면 OS는 올라갔습니다. 이제 "죽지 않고 / 멀리서 관리되는" 장비로 다듬는 단계로 갑니다.

2. BIOS — 정전 후 자동으로 다시 켜기

전원 인입이 불규칙한 현장(순간 정전·차단기 내려감)에서 전기가 다시 들어왔을 때 PC가 꺼진 채로 남지 않고 스스로 켜지게 만드는 설정입니다. 무인 장비라면 사실상 필수.

🔌
핵심 한 줄. BIOS의 "AC 전원 복구 시 동작" 항목을 "항상 켜짐(Power On)"으로 바꾸면 됩니다. 메인보드 제조사마다 메뉴 이름만 다를 뿐 기능은 같습니다.

1) BIOS 진입

  1. PC를 켜자마자 BIOS 키를 연타: 보통 Del 또는 F2 (제조사별: ASUS·MSI·기가바이트=Del, 일부 노트북=F2)
  2. 이미 우분투가 켜진 상태라면: sudo systemctl reboot --firmware-setup 로 재부팅하면 바로 BIOS로 진입

2) 설정 항목 찾기 — 브랜드 몰라도 찾는 법

⚠️
BIOS는 제조사·모델·버전마다 메뉴 이름과 위치가 다 다릅니다. 아래 표는 대표 예시일 뿐이고, 내 화면엔 똑같이 안 나올 수 있어요. 그래서 "정확한 메뉴명"을 외우기보다 아래 키워드 사냥법으로 찾는 게 확실합니다.

화면이 어떻게 생겼든, 이 3가지만 기억하면 됩니다:

  1. 위치 — 거의 항상 Power, Advanced, APM(Advanced Power Management) 메뉴 아래. 이 메뉴들부터 열어보세요.
  2. 이름 — 항목 이름에 AC · Power Loss · Power Failure · Restore · After Power · AC BACK 중 하나는 반드시 들어갑니다. 이 단어가 보이는 항목을 찾으세요.
  3. 값 — 그 항목을 Power On(또는 On / Last State)으로. (값별 차이는 아래 3) 표 참고)
🔎
그래도 못 찾겠으면: ① 메인보드/PC 모델명을 확인해(본체 스티커, 또는 우분투에서 sudo dmidecode -t baseboard) → ② 구글에 "[모델명] restore on AC power loss" 또는 "[모델명] 정전 자동 켜짐 bios"로 검색하면 그 보드 전용 위치가 나옵니다. ③ 그래도 애매하면 BIOS 화면을 휴대폰으로 찍어 담당자에게 보내 물어보세요(화면만 보면 바로 짚어줄 수 있음).

대표 예시 (보드마다 다르니 참고용)

제조사 / BIOS메뉴 경로 (예시)항목 이름 (예시)
ASUSAdvanced → APM ConfigurationRestore AC Power Loss
MSISettings → Advanced → Power Management SetupRestore after AC Power Loss
GIGABYTESettings → Platform Power (또는 BIOS)AC BACK / ErP
ASRockAdvanced → ACPI ConfigurationRestore on AC/Power Loss
Intel NUCPower → Secondary Power SettingsAfter Power Failure
Dell / HP / LenovoPower ManagementAC Recovery / After Power Loss

3) 값 설정

  1. 찾은 항목의 값을 Power On (또는 On / Always On)으로 변경
  2. 선택지에 Last State(직전 상태)가 있으면 그 의미는 아래 표 참고 — 무인 장비엔 Power On 권장
  3. F10 → Save & Exit (저장 후 종료)
값전기 복구되면언제 쓰나
Power On무조건 켜짐무인 장비 권장. 항상 켜져 있어야 하는 PC
Last State정전 직전 상태로 복원 (켜져 있었으면 켜짐)평소 켜두는 장비. 단, 누가 꺼둔 상태였다면 안 켜짐
Power Off꺼진 채로 유지 (기본값)사람이 직접 켜는 일반 PC. 무인 장비엔 부적합
⚠️
ErP / Deep Sleep(딥슬립) 옵션이 켜져 있으면 절전이 너무 깊어 AC 복구 신호를 못 받을 수 있습니다. 자동 켜짐이 안 되면 이 ErP 항목을 Disabled로 두세요.
🧪
검증: PC가 켜진 상태에서 전원 케이블(또는 멀티탭)을 뽑았다 다시 꽂아 보세요. 잠시 후 저절로 켜지면 성공입니다.

3. 네트워크 — 고정 IP 설정

원격 접속(SSH·RustDesk)을 하려면 장비의 IP가 바뀌지 않아야 합니다. DHCP 자동 할당 대신 고정 IP를 박아둡니다.

💡
설정 전에 네트워크 담당자에게 받아둘 값: IP 주소, 서브넷(보통 /24), 게이트웨이, DNS. 예시로 아래는 192.168.0.50, 게이트웨이 192.168.0.1, DNS 8.8.8.8을 씁니다 — 현장 값으로 바꾸세요.

데스크탑이라면 화면에서 클릭으로 하는 게 가장 쉽고 안전합니다.

  1. 우측 상단 네트워크 아이콘 클릭 → 유선 연결됨 → 설정 (또는 설정 → 네트워크)
  2. 해당 유선 연결의 톱니바퀴(⚙️) 클릭
  3. IPv4 탭 → 방식을 수동(Manual)으로
  4. 주소 칸에 입력:
    주소(Address)192.168.0.50
    네트마스크255.255.255.0 (= /24)
    게이트웨이192.168.0.1
  5. DNS 칸에 8.8.8.8, 1.1.1.1 입력 (자동 끄기)
  6. 적용 → 유선 연결을 껐다 켜기(토글)로 재적용

서버형·헤드리스 장비는 netplan으로 설정합니다(우분투 표준).

# 1) 인터페이스 이름 확인 (예: enp3s0, eno1)
ip -br a

# 2) netplan 설정 파일 편집 (이름은 환경마다 다름)
sudo nano /etc/netplan/01-netcfg.yaml

아래 내용으로 작성 (인터페이스명·IP는 실제 값으로):

network:
  version: 2
  renderer: NetworkManager   # 데스크탑이면 NetworkManager, 서버면 networkd
  ethernets:
    enp3s0:
      dhcp4: false
      addresses: [192.168.0.50/24]
      routes:
        - to: default
          via: 192.168.0.1
      nameservers:
        addresses: [8.8.8.8, 1.1.1.1]
# 3) 문법 검사 후 적용
sudo netplan try        # 120초 안에 Enter 안 누르면 자동 원복(안전)
sudo netplan apply
⚠️
YAML은 들여쓰기(공백 2칸)에 민감합니다. 탭 쓰지 말고 공백으로. 원격에서 작업 중이라면 설정이 틀리면 연결이 끊길 수 있으니 netplan try(자동 원복)를 먼저 쓰세요.

확인

# IP가 의도대로 박혔는지
ip -br a

# 게이트웨이·인터넷 연결 확인
ping -c 3 8.8.8.8
ping -c 3 google.com    # DNS까지 정상이면 도메인도 응답
✅
이제 이 IP는 재부팅·정전 후에도 그대로입니다. 이 주소로 SSH·RustDesk를 붙이면 됩니다. IP를 어딘가 기록해 두세요.

4. 비밀번호·팝업 제거 (무인화)

사람이 없어도 부팅만으로 화면이 떠 있고, 앱 실행 때 비밀번호 팝업이 안 뜨게 만듭니다. 정전 후 자동 재부팅(2번)과 짝을 이루는 설정입니다.

🔓
보안 트레이드오프. 아래 설정들은 "그 PC를 켤 수 있는 사람이면 누구나 화면에 접근"하게 만듭니다. 물리적으로 안전한 곳에 둔 무인 장비에만 적용하세요. 공용·이동 장비엔 권장하지 않습니다. (참고: sudo 비밀번호는 보안상 그대로 둡니다.)

① 부팅 시 자동 로그인

전원이 들어오면 로그인 화면을 거치지 않고 바로 바탕화면까지 진입합니다.

  1. 설정 → 시스템 → 사용자 (또는 설정 → 사용자)
  2. 우측 상단 잠금 해제(Unlock) → 비밀번호 입력
  3. 자동 로그인(Automatic Login) 스위치를 켬

GDM 설정 파일에서 직접 켭니다. 사용자명을 실제 계정으로 바꾸세요.

sudo nano /etc/gdm3/custom.conf
# [daemon] 섹션 아래에 추가/수정
[daemon]
AutomaticLoginEnable = true
AutomaticLogin = 사용자명
# 적용 (재부팅)
sudo reboot

② 키링(keyring) 잠금해제 팝업 제거

Chrome·RustDesk 등을 실행할 때 뜨는 "잠금 해제 / Authentication required / 키링 암호 입력" 팝업의 원인입니다. 자동 로그인을 켜면 로그인 비번으로 키링이 자동 해제되지 않아 이 팝업이 생깁니다. 키링 비밀번호를 빈 값으로 만들면 팝업이 사라집니다.

  1. 앱 목록에서 "암호 및 키" (Passwords and Keys / seahorse) 실행
    없으면 설치: sudo apt install -y seahorse
  2. 왼쪽 로그인(Login) 키링에서 우클릭 → 비밀번호 변경(Change Password)
  3. 현재 비밀번호(=로그인 비번) 입력 → 새 비밀번호를 비워 두고 확인
  4. "암호화하지 않고 저장하시겠습니까?" 경고 → 계속(Continue)
💡
키링이 꼬여서 위 방법이 안 먹으면, 키링 파일을 지우고 다시 만들 수 있습니다(저장된 와이파이·앱 비밀번호도 초기화됨): 
rm -f ~/.local/share/keyrings/login.keyring ~/.local/share/keyrings/user.keystore
# 로그아웃 후 다시 로그인하면 빈 비번 키링이 새로 생성됨

③ 화면잠금 · 절전 끄기

일정 시간 후 화면이 꺼지거나 잠겨서 비밀번호를 요구하는 것을 막습니다.

  • 설정 → 전원 → "화면 끄기(Blank Screen)" 안 함(Never), "자동 절전(Automatic Suspend)" 끔
  • 설정 → 개인정보 → 화면 잠금 → "자동 화면 잠금" 끔, "빈 화면 지연 시 잠금" 끔
# 자동 화면 잠금 끄기
gsettings set org.gnome.desktop.screensaver lock-enabled false

# 화면 자동 꺼짐(블랭크) 끄기 — 0 = 안 함
gsettings set org.gnome.desktop.session idle-delay 0

# 절전(서스펜드) 끄기 (AC·배터리 양쪽)
gsettings set org.gnome.settings-daemon.plugins.power sleep-inactive-ac-type 'nothing'
gsettings set org.gnome.settings-daemon.plugins.power sleep-inactive-battery-type 'nothing'
⚠️
gsettings는 현재 로그인한 그래픽 세션 안에서 실행해야 적용됩니다(SSH 원격 셸에서 그냥 치면 안 먹을 수 있음). 데스크탑의 터미널 앱에서 실행하세요.
✅
이제 전원만 들어오면 → 자동 로그인 → 바탕화면 → 앱 실행까지 사람 손 없이 진행됩니다.

5. Git 설치

소스 코드를 받고 관리하는 도구. apt로 한 줄이면 설치됩니다.

# 설치
sudo apt update
sudo apt install -y git

# 버전 확인
git --version

# 커밋에 찍힐 이름·이메일 등록 (1회)
git config --global user.name "Your Name"
git config --global user.email "you@maiot.kr"

# 기본 브랜치 이름을 main 으로
git config --global init.defaultBranch main
💡
GitHub 등 비공개 저장소를 받을 거면 SSH 키를 만들어 등록하는 게 편합니다(6번에서 만든 키 재사용 가능): 
ssh-keygen -t ed25519 -C "you@maiot.kr"
cat ~/.ssh/id_ed25519.pub   # 출력된 공개키를 GitHub → Settings → SSH keys 에 등록

6. SSH 설치 (원격 터미널)

다른 PC에서 이 장비에 터미널로 접속해 명령을 내릴 수 있게 합니다. 우분투 데스크탑은 SSH 서버가 기본 미설치라 따로 깔아야 합니다.

# SSH 서버 설치
sudo apt update
sudo apt install -y openssh-server

# 서비스 시작 + 부팅 시 자동 실행 등록
sudo systemctl enable --now ssh

# 동작 확인 (active (running) 이면 정상)
sudo systemctl status ssh

방화벽 열기 (ufw 쓰는 경우)

sudo ufw allow ssh        # 22번 포트 허용
sudo ufw status

다른 PC에서 접속

# 형식: ssh 계정명@고정IP  (3번에서 정한 IP)
ssh maiot@192.168.0.50
🔑
비밀번호 없이 접속(권장): 접속하는 쪽 PC에서 키를 만들어 장비에 복사하면 이후 비번 없이 들어갑니다. 
# 접속하는 내 PC에서
ssh-keygen -t ed25519              # 키 없으면 생성
ssh-copy-id maiot@192.168.0.50     # 공개키를 장비에 등록
⚠️
Connection refused가 뜨면: ① SSH 서버가 안 떠 있거나(systemctl status ssh) ② 방화벽이 22번을 막았거나 ③ IP가 틀린 경우입니다. 위에서부터 차례로 확인하세요.

7. Docker 설치

컨테이너로 앱을 돌리는 도구. 우분투 기본 저장소 버전은 오래됐을 수 있어, Docker 공식 저장소에서 설치하는 방법을 씁니다(공식 권장).

💡
아래는 공식 문서의 "apt 저장소로 설치" 절차입니다. 명령을 위에서부터 순서대로 그대로 실행하면 됩니다. (빠르게 끝내려면 공식 편의 스크립트 curl -fsSL https://get.docker.com | sudo sh 도 있지만, 운영 장비엔 아래 정식 방법을 권장.)

1) 기존 충돌 패키지 제거 + 사전 도구

# 예전 docker 패키지가 있으면 제거 (없으면 그냥 통과)
for p in docker.io docker-doc docker-compose podman-docker containerd runc; do sudo apt remove -y $p; done

# HTTPS 저장소 사용 도구
sudo apt update
sudo apt install -y ca-certificates curl

2) Docker 공식 GPG 키 + 저장소 등록

# 공식 GPG 키 내려받기
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

# apt 저장소 추가 (현재 우분투 버전 코드네임 자동 인식)
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] \
  https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

3) 설치

sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

# 설치 확인 (hello-world 컨테이너 실행)
sudo docker run hello-world

4) sudo 없이 docker 쓰기 (권장)

# 현재 사용자를 docker 그룹에 추가
sudo usermod -aG docker $USER

# 그룹 적용 — 로그아웃 후 재로그인(또는 재부팅)해야 반영됨
# 확인: sudo 없이 실행되면 성공
docker run hello-world
docker compose version
⚠️
usermod 후엔 반드시 로그아웃→재로그인(또는 재부팅) 해야 그룹이 적용됩니다. 안 하면 계속 permission denied ... docker.sock이 뜹니다.
🔁
부팅 시 도커가 자동 시작되도록: sudo systemctl enable --now docker (대개 설치 시 이미 켜져 있음).

8. RustDesk 설치 (원격 데스크탑)

화면을 그대로 원격에서 보고 조작하는 도구(TeamViewer 대체). 무인 장비를 멀리서 GUI로 관리할 때 씁니다.

1) 설치 (.deb 내려받아 설치)

  1. github.com/rustdesk/rustdesk/releases 에서 최신 ...-x86_64.deb 파일 다운로드 (우분투 22.04+는 보통 이 파일)
  2. 설치 — 둘 중 하나:
# 방법 A) 명령어로 설치 (파일명은 받은 버전으로)
cd ~/Downloads
sudo apt install -y ./rustdesk-*.deb

# 방법 B) 파일 매니저에서 .deb 더블클릭 → "소프트웨어 설치"
💡
의존성 에러가 나면 sudo apt --fix-broken install 로 해결됩니다. 설치 후 앱 목록에 RustDesk가 생깁니다.

2) 무인 접속(상시 비밀번호) 설정

현장에 사람이 없어도 원격에서 바로 붙으려면 고정 비밀번호를 정하고 백그라운드 서비스를 켜둡니다.

  1. RustDesk 실행 → 좌측 이 데스크톱(This Desk)의 ID를 기록 (원격에서 이걸로 접속)
  2. 우측 비밀번호 옆 ⋮ (점 세 개) → 비밀번호 설정(Set permanent password) → 상시 비밀번호 지정
  3. 메뉴 → 설정(Settings) → 보안(Security):
    • "부팅 시 시작 / 서비스로 실행" 켜기 → 로그인 안 해도 접속 가능
    • 비밀번호 방식을 "영구 비밀번호 사용"으로
  4. (선택) 자체 릴레이 서버가 있으면 설정 → 네트워크에 ID/릴레이 서버 주소 입력. 없으면 공용 서버로 동작
✅
접속 테스트: 다른 PC의 RustDesk에서 기록해 둔 ID 입력 → 연결 → 상시 비밀번호 입력. 화면이 뜨면 성공.
🛡️
상시 비밀번호는 곧 그 장비의 원격 열쇠입니다. 충분히 길고 추측 어려운 값으로 정하고, 아무 데나 적어두지 마세요. 같은 망 안에서만 쓸 거면 ID/릴레이 서버를 사내에 두는 편이 안전합니다.
